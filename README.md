# UberPersona — проект живого ИИ-персонажа

UberPersona объединяет универсальность кодового агента, сменные рабочие места, личность и память с быстрыми действиями для живого общения и игр. Этот репозиторий — открытое описание и пример структуры. Реализация ведётся отдельно в закрытом `uberpersona`.
